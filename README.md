# Kommentar till sambolagen (2003:376)

Kommentar till svensk författning: **Sambolag (2003:376)** (SFS 2003:376). Kommentaren omfattar **33 enheter** (32 paragrafer, 1–32 §§, samt övergångsbestämmelserna) fördelade på 2 kommentarskapitel; vid varje paragraf återges dess ordagranna lydelse följd av en kommentar.

Lydelse enligt: konsoliderad text i Svensk författningssamling, **ändrad t.o.m. SFS 2025:563** (Regeringskansliets rättsdatabaser / Riksdagens öppna data, publicerad 2025-10-17).

Källa: [rkrattsbaser.gov.se/sfst?bet=2003:376](https://rkrattsbaser.gov.se/sfst?bet=2003%3A376) · [data.riksdagen.se/dokument/sfs-2003-376](https://data.riksdagen.se/dokument/sfs-2003-376.json)

Kommentaren har utarbetats **uteslutande på grundval av lokalt material** (den officiella konsoliderade texten i SFS och författningsregistret), utan användning av kommersiella juridiska databaser.
